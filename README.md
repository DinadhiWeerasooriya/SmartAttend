SmartAttend – Smart University Attendance Management System
Project Overview

SmartAttend is a QR-based university attendance management system designed to simplify and improve the traditional attendance-taking process.

The system provides separate interfaces for administrators, lecturers, and students, allowing attendance management to be handled through a centralised digital platform.

## Key Features

- **Dynamic QR Attendance:** Students mark attendance by scanning QR codes generated by lecturers.
- **QR Code Rotation:** QR codes refresh every 30 seconds to improve attendance security.
- **Location Verification:** Checks whether students are within the permitted classroom location.
- **Student Management:** Administrators can manage student accounts and information.
- **Lecturer Management:** Supports lecturer accounts and subject assignments.
- **Attendance Records:** Students can view their attendance history.
- **Reports:** Lecturers and administrators can view and download attendance reports.
- **Role-Based Access:** Separate access for administrators, lecturers and students.

## System Architecture

The application follows a client-server architecture.

1. Users interact with the SmartAttend frontend.
2. The backend processes requests and application logic.
3. The backend communicates with Supabase.
4. PostgreSQL stores and retrieves application data.
5. Google Cloud Run hosts the deployed application.

## Development Approach

SmartAttend was developed using AI-assisted development, also known as vibe coding, with Google AI Studio.

The project involved database integration, application development, cloud deployment, testing and debugging.

## Project Purpose

The goal of SmartAttend is to provide a more convenient and structured approach to university attendance management while reducing the limitations of traditional manual attendance methods.
